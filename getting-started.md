# Getting Started
## Complete your first daily check-in
Before loging your first workout, complete your daily-check in. If this is your first time visiting the **Home** dashbaord, the daily check in dialogue will be outlined in red.
[image]
#### Weight
1. Input your current body weight at the time of daily check-in
    -Loging your daily check-in at the same time everyday will provide the most accurate progress.
2. Log any notes related to your daily check-in such as morning weight and post meal weight.
3. Open the body composition dropdown and log individual measurements and body fat percentage. Select **Next** once compelte.
#### Welness
1. Log sleep and quality of sleep for the previous night. 
2. Use the sliding adjusters to track mental health markers such as mood, stress, energy, etc. 
3. Using the sliders, input areas of fatigue.
4. Log daily activity monitors such as steps, resting HR, and HRV. Add any additional notes using the drop down and select **Next** once compelte. 
#### Nutrition
1. Input daily nutrition totals such as carbs, fats, protein, and total calories. Once compelte, select **Next**

Once compelte, you can edit or update any values by clicking on the Daily check-in box again.

## Add your first goals
1. Select **+ New** on on the Goals dialogue.
2. Set your first goal:
| Syntax | Description |
| ------ | ----------  |
| Field | Description |
| Goal Type | Choose the goal type such as Bodyweight, E1RM, Custom, and more. |
| Title | Add a title for the set goal. |
| Deadline | Set a tracker for the deadline you wish to achieve the goal by. |
| Notes | Add any additional notes for tracking the goal. |


Select *Home* from the primary navigation.
